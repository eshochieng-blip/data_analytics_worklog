## Projects and Exercises

### Organic Livestock Statistical Analysis

**Objective:** Determine whether certified organic livestock counts changed significantly between 2008 and 2011 across U.S. states.

**Tasks Completed:**

* Cleaned and prepared the dataset.
* Calculated descriptive statistics.
* Formulated statistical hypotheses.
* Conducted paired t-test analysis.
* Compared livestock counts across regions.
* Interpreted statistical significance and test results.

**Skills Applied:**

* Data cleaning
* Descriptive statistics
* Hypothesis testing
* Statistical interpretation
